# Demo Mode Instructions

Since you're having API key issues, you can use **mock mode** to record your demo video with realistic-looking evidence.

## How to Enable Mock Mode:

1. The system already falls back to mock data when Gemini fails
2. Your current setup will show evidence, but it says "analysis unavailable"
3. For a clean demo, we can modify the mock data to look like real analysis

## What You'll See in Mock Mode:

- 2 sample CCTV tenders from Kolkata
- Match scores: 85% and 72%
- Status: "possibly_eligible"  
- Recommendation: "Review requirements carefully before bidding"
- Evidence: Will show "analysis unavailable" message

## To Get Real Evidence in Demo:

You need to get a proper API key (starts with `AIzaSy...`) from:
https://aistudio.google.com/apikey

Look for "Create API key" (not OAuth credentials).
